# 좌석예보 (가칭)

> 지도 앱은 **빠른 버스**를, 좌석예보는 **탈 수 있는 버스**를 알려줍니다.

수원 → 서울 광역버스 이용자를 위해 **어느 정류장에서 어떤 버스를 타야 가장 빨리 도착하는지** 추천하는 안드로이드 앱 프로젝트입니다.
출근 시간대 광역버스의 잔여 좌석 데이터를 모아, 버스마다 **탑승 성공 확률**을 예측하고 이를 경로 추천에 반영합니다.

국민대학교 수업 팀 프로젝트입니다.

## 왜 필요한가

- 광역버스(직행좌석형)는 좌석이 차면 정류장에서 더 태우지 않고 지나갑니다.
- 기존 지도 앱은 최단 시간만 계산해서, 출근 시간대에는 **만석이라 탈 수 없는 버스**를 추천하기도 합니다.
- 기존 앱은 '지금' 잔여 좌석만 보여주고, 내가 정류장에 도착할 때의 상황은 알려주지 않습니다.

## 핵심 아이디어

```
총 소요시간 = 정류장까지 걷는 시간 + 기대 대기시간 + 버스 이동시간
기대 대기시간 = 평균 대기 + 배차간격 × (1 − p) / p      (p = 탑승 성공 확률)
```

탑승 확률이 낮은 버스는 "만석이라 다음 차를 기다릴 시간"이 늘어나서 추천 순위가 내려갑니다.

## 주요 기능 (계획)

- 탑승 확률을 반영한 정류장·노선 추천
- 시간대별 좌석 예보
- 집에서 나설 시각 알림
- 실시간 버스 위치·잔여 좌석 확인
- 회원가입, 즐겨찾기, 탑승 피드백

## 기술 스택

| 영역 | 기술 |
|---|---|
| 앱 | Android Studio, Java, Retrofit, Firebase Cloud Messaging |
| 데이터 수집 · AI | Python, pandas, scikit-learn (Random Forest) |
| 서버 | FastAPI |
| 사용자 관리 · DB | Firebase Authentication, Cloud Firestore, SQLite |
| 데이터 | 공공데이터포털 경기도 버스 Open API, 경기데이터드림 |

## 사용 데이터 (Open API)

| API | 용도 |
|---|---|
| 경기도_버스위치정보 조회 | 노선 위 모든 차량의 현재 위치·잔여 좌석 (수집의 핵심) |
| 경기도_버스도착정보 조회 | 정류장별 도착 예정 버스·잔여 좌석 |
| 경기도_버스노선 조회 | 노선 ID, 정류장 순서, 배차간격 |
| 경기도 버스정류소 (경기데이터드림) | 정류장 위치, 경유 노선 |

## 현재 대상

- 탑승 정류장: 삼성1차아파트 (정류소번호 04007, 서울 방향)
- 노선: 8800(서울역), 3007(강남역), 7001(사당역), 3008(강남역)
- 수집 시간: 평일 06:00 – 10:00, 1분 간격

## 실행 방법

```bash
pip install requests pandas scikit-learn joblib

# 1) 인증키 설정: api_key.example.py 를 복사해 api_key.py 로 만들고 키 입력
# 2) 노선 ID · 정류장 순번 찾기 (결과를 config.py 에 입력)
python find_ids.py

# 3) 잔여 좌석 수집 (bus_seats.csv 에 저장, Ctrl+C 로 중지)
python collect.py

# 4) 평일 10일 이상 모은 뒤 모델 학습
python train.py
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `config.py` | 노선, 탑승 정류장 순번, 수집 시간 등 설정 |
| `find_ids.py` | 노선 ID와 정류장 순번 검색 도우미 |
| `collect.py` | 버스위치정보 API로 잔여 좌석을 1분마다 수집 |
| `train.py` | 탑승 성공 여부를 Random Forest로 학습·평가 |
| `survey_form.gs` | 이용자 설문 구글폼 자동 생성 스크립트 (Google Apps Script) |

## 탑승 성공의 정의

좌석제 버스는 좌석이 남아 있는 한 줄 선 사람을 모두 태웁니다.
그래서 **탑승 정류장을 떠난 직후 잔여 좌석이 1석 이상이면 "탑승 성공"** 으로 봅니다.
출발점(수원버스터미널)은 항상 좌석이 비어 있어 의미가 없기 때문에, 실제 탑승 정류장을 기준으로 측정합니다.
