# 좌석예보 (가칭)

> 지도 앱은 **빠른 버스**를, 좌석예보는 **탈 수 있는 버스**를 알려줍니다.

수원 → 서울 광역버스 이용자를 위해 **어느 정류장에서 어떤 버스를 타야 가장 빨리 도착하는지** 추천하는 안드로이드 앱 프로젝트입니다.
출근 시간대 광역버스의 잔여 좌석 데이터를 모아, 버스마다 **탑승 성공 확률**을 예측하고 이를 경로 추천에 반영합니다.

국민대학교 수업 팀 프로젝트입니다.

## 왜 필요한가

- 광역버스(직행좌석형)는 좌석이 차면 정류장에서 더 태우지 않고 지나갑니다.
- 기존 지도 앱은 최단 시간만 계산해서, 출근 시간대에는 **만석이라 탈 수 없는 버스**를 추천하기도 합니다.
- 기존 앱은 '지금' 잔여 좌석만 보여주고, 내가 정류장에 도착할 때의 상황은 알려주지 않습니다.

## 핵심 아이디어

집 주변 **여러 정류장 × 여러 노선** 조합마다 아래 값을 계산해, 가장 빨리 도착하는 조합을 추천합니다.

```
총 소요시간 = 정류장까지 도보 + 기대 대기시간 + 버스 이동시간(서울 도착 지점까지) + 국민대까지 환승
기대 대기시간 = 배차간격 ÷ 2 + 배차간격 × (1 − p) / p      (p = 그 정류장에서의 탑승 성공 확률)
```

- 탑승 확률이 낮은 버스는 "만석이라 다음 차를 기다릴 시간"이 늘어나서 순위가 내려갑니다.
- 몇 분 더 걸어서 **앞 정류장**에서 타면 좌석이 남아 있을 확률이 높아지는데, 이 대가(도보 시간)와 이득(대기 감소)을 함께 비교합니다.

## 실시간 대안 안내: 기다릴까, 걸어갈까, 다른 버스를 탈까?

정류장에서 버스가 만석으로 올 것 같을 때, 지금 이 순간의 버스 위치·잔여 좌석으로 세 가지 선택지를 비교해 추천합니다.

| 선택지 | 내용 | 이럴 때 추천 |
|---|---|---|
| ① 기다리기 | 지금 정류장에서 다음 버스를 기다림 | 첫 차는 만석이지만 바로 뒤 차에 자리가 있을 때 |
| ② 걸어가기 | 전 정류장으로 걸어가 같은 버스를 먼저 탐 | 집 앞에선 만석이지만 앞 정류장에선 자리가 있을 때 |
| ③ 다른 버스 | 다른 노선을 타고 다른 환승 경로로 이동 | 평소 노선이 줄줄이 만석일 때 |

- 다가오는 버스마다 **도착 때 예상 좌석 = 현재 좌석 − 정류장당 좌석 감소 × 남은 정류장 수** 로 탑승 확률을 계산합니다.
- 첫 차부터 차례로 타 보고, 만석이면 다음 차를 기다린다고 보고 **기대 탑승 시각**을 구한 뒤 이동·환승 시간을 더해 비교합니다.
- 걸어가는 동안 지나가 버리는 버스는 제외합니다.

## 주요 기능 (계획)

- 탑승 확률을 반영한 정류장·노선 추천
- 시간대별 좌석 예보
- 집에서 나설 시각 알림
- 실시간 버스 위치·잔여 좌석 확인
- 회원가입, 즐겨찾기, 탑승 피드백

## 실행 방법

```bash
pip install requests pandas scikit-learn joblib

# 1) 인증키 설정: api_key.example.py 를 복사해 api_key.py 로 만들고 키 입력
#    (공공데이터포털 · 경기데이터드림 · ODsay · TMAP 키)
# 2) 주변 정류장과 서울행 노선 찾기 → 결과를 config.py 에 입력
python find_nearby.py
python find_ids.py

# 3) 잔여 좌석 수집 (bus_seats.csv 에 저장, Ctrl+C 로 중지)
python collect.py

# 4) 평일 10일 이상 모은 뒤 모델 학습
python train.py

# 5) 정류장·노선 추천 (예: 월요일 07:30 집에서 출발)
python recommend.py 07:30 0

# 6) 지금 실시간 대안 안내 (기다리기 / 걸어가기 / 다른 버스)
python live_recommend.py

# 환승 경로·도보 시간만 따로 보기 / 키·IP 점검 (ODsay는 등록한 공인 IP에서만 작동)
python transit.py
python check_keys.py

# 시연: 출근 시간 가상 상황 3가지
python demo_scenarios.py
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `config.py` | 후보 정류장(도보 시간), 노선별 정류장 순번·서울 도착 지점, 수집 시간 등 설정 |
| `find_ids.py` | 노선 ID와 정류장 순번 검색 도우미 |
| `find_nearby.py` | 기준 정류장 주변(반경 700m)의 정류장과 서울행 광역버스·정류장 순번 조회 |
| `collect.py` | 버스위치정보 API로 잔여 좌석을 1분마다 수집 |
| `train.py` | 노선 × 정류장별 탑승 성공 여부를 Random Forest로 학습·평가, 이동시간·배차 실측 |
| `recommend.py` | 출발 시각을 넣으면 정류장·노선 조합을 기대 도착 시각 순으로 추천 (출발 전 계획용) |
| `live_recommend.py` | 실시간 버스 위치·좌석으로 기다리기 / 걸어가기 / 다른 버스 중 추천 |
| `demo_scenarios.py` | 출근 시간 가상 상황 3가지로 실시간 추천 시연 |
| `transit.py` | ODsay 환승 경로 · TMAP 도보 시간 조회 (하루 한 번 조회해 저장) |
| `check_keys.py` | 지금 공인 IP 확인 + API 키 작동 점검 |
| `survey_form.gs` | 이용자 설문 구글폼 자동 생성 스크립트 (Google Apps Script) |

## 탑승 성공의 정의

좌석제 버스는 좌석이 남아 있는 한 줄 선 사람을 모두 태웁니다.
그래서 **각 후보 정류장을 떠난 직후 잔여 좌석이 1석 이상이면 "그 정류장에서 탑승 성공"** 으로 봅니다.
출발점(수원버스터미널)은 항상 좌석이 비어 있어 의미가 없기 때문에, 실제 탑승 정류장을 기준으로 측정합니다.
