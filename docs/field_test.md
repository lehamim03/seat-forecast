## 전날 준비
1. **서버 컴퓨터**: 시험 시간 내내 켜 두고 `python server.py`. 그 컴퓨터의 공인 IP 가 ODsay 에 등록돼 있어야 함 (`python check_keys.py` 에서 ODsay ✅). 집에서 켤 거면 집 IP 도 등록
2. **휴대폰이 서버에 닿게**: 정류장의 휴대폰은 LTE 라 학교 내부 주소(10.x)로는 못 들어옴. 서버 컴퓨터에서
   `cloudflared tunnel --url http://localhost:8000` → 나오는 `https://….trycloudflare.com` 주소를 앱 SERVER_BASE_URL 로 (실행할 때마다 주소가 바뀌니 시험 날 아침에 확인)
   - 공개 주소이므로 시험 동안 `FIREBASE_PROJECT_ID` 를 정해 로그인한 사용자만 받기 권장
3. **앱**: 위 주소로 빌드한 시연 앱 APK 를 각자 휴대폰에 설치, 위치 권한 허용, 로그인
4. **확인**: 휴대폰 브라우저로 `<주소>/health` → `{"status":"ok"}`

## 정류장에서 (1명 기준 10분)
1. 정류장 도착 → 앱 열기 → 출발지 "현재 위치", 도착지 "국민대학교"
2. 추천 화면 **화면 녹화 시작** (첫 카드의 노선 · 탑승 확률 · 도착 예상이 보이게)
3. 버스가 오면 탑승 시도 → 앱에서 **탔어요 / 못 탔어요** (메모: 줄 선 인원 대략, 못 탔으면 이유)
4. 다음 차까지 기다렸다면 그 차도 같은 방법으로 기록
5. 백업 기록 (앱이 안 될 때): 날짜 · 시각 · 정류장 · 노선 · 앱 확률 · 탔는지 · 줄 선 인원 → 팀 시트
